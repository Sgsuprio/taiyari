## 6. Hosting and domain checklist
1. Pick the app address: a subdomain of a domain you own, for example **taiyari.[yourdomain]**.
2. In your GitHub repo: Settings, Pages, Custom domain, enter that address, tick Enforce HTTPS. GitHub gives the DNS record to add (a CNAME to [username].github.io).
3. Add that record where you manage the domain's DNS. Only add new records. Do not change existing ones.
4. Resend: Domains, Add domain, use the same domain or a sending subdomain. Add the records Resend shows, wait for Verified. Then in Supabase: Authentication, Emails, SMTP Settings, set Sender email to no-reply@[that domain].
5. In the repo add an empty file named **.nojekyll** (Add file, Create new file; if it will not save empty, type one space).
6. Package it: pwabuilder.com, enter your app address, Package for stores, Google Play. Choose a permanent package ID such as **[com.yourname.taiyari]**. Keep the downloaded signing key file and password safe: you need the same key for every update.
7. Play Console: create the app, upload the .aab to **Closed testing**. After the first upload open Setup, App integrity, App signing and copy the **SHA-256 fingerprint**.
8. In the repo create **.well-known/assetlinks.json** with this content (replace the two values), then wait a minute and reopen the app. The browser bar should disappear:

```json
[{"relation":["delegate_permission/common.handle_all_urls"],"target":{"namespace":"android_app","package_name":"[com.yourname.taiyari]","sha256_cert_fingerprints":["[PASTE SHA-256 FROM PLAY CONSOLE]"]}}]
```

## 7. Testing and release
- New personal accounts need a closed test with at least 12 testers opted in for 14 days in a row, then apply for production access.
- Ask 15 or more friends and classmates to join with their Gmail address, so you still have 12 if a few leave. Sign-ups need the Resend domain verified (step 4).
- Keep a short list of what testers should try: sign up, take a quiz, review results, save a note, AI practice, delete account.
- Every new upload needs a higher version code (PWABuilder asks for the version when you package again).
